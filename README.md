# SteamAuthOnOculus
This is a mod targeted towards authenticating with your Steam account on the Rift build of Gorilla Tag

In order for this to work you need to own Gorilla Tag on the Rift store and Steam store

# Purpose of this mod
If you have ever played Gorilla Tag through SteamVR with Oculus Link you would know that its pretty jittery and the movement sucks, now with this mod you will be able to use your Steam account natively with Rift.


# How To Use
Obviously put the mod in your BepInEx/plugins folder of the Rift build, now with the Steam build go to Gorilla Tag_Data/Plugins and find the steam_api64.dll and paste it into the Rift build Gorilla Tag_Data/Plugins
